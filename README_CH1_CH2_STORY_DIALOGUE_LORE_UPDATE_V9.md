# CH1 + CH2 Story Dialogue / Core Lore Update V9

적용 기준: Chapter 2 통합 v6 적용 프로젝트 위 증분 패치.

## Chapter 1
- 프롤로그를 최신 35줄 버전으로 전면 교체.
- 첨성대 코어 / 코어 영역 / 실제 첨성대와의 연결 관계를 프롤로그에서 설명.
- 첫 정화 후 학생증 최초 대화, 첨성대 코어 설명, 정화 에너지 설명을 요청본으로 교체.
- 정화율 100% 이후 코어 영역 및 코어 영역 이동 기능 설명 추가.
- 현실 서버실 이동 대신 별빛 포탈을 생성해 `첨성대 코어 · 학사 영역`으로 진입하도록 변경.
- 게이트키퍼 내부의 두 별 신호 감지 대사 추가.
- 챕터 1 별 이름을 `시작의 별`, `적응의 별`로 변경.
- 별 회수 뒤 코어 연결률 상승 및 코어 영역 이동 기능 안정화 대사 반영.
- 프롤로그 대사 수 증가에 맞춰 장면 데이터와 기존 프롤로그 일러스트/효과 타이밍도 재매핑.

## Chapter 2
- 감정 자체가 오염이라는 인상을 제거하고, 오염이 책임 회피/시험 불안/시간 압박을 비정상적으로 증폭한다는 설정으로 수정.
- 일반 전투 종료 뒤 강한 오염 반응이 미회수 별 신호를 가린다는 설명으로 수정.
- 팀원 사과 장면에서 정화가 사람의 의지를 직접 바꾼다는 인상을 제거.
- 팀원들의 실제 업로드 이후 별 신호가 다시 탐지되는 흐름 추가.
- CH1에서 안정화된 코어 영역 이동 기능을 재사용해 포탈을 생성하도록 수정.
- 포탈 생성 직후 열람실 자리 만료 10분 연출과 강제 이동 대사 반영.
- 팀플 블랙홀의 감정 증폭/에너지원/별 신호 차폐 설정을 요청본으로 수정.
- 보스 격파 후 시험의 별 / 팀플의 별 회수 및 네 별의 코어 연결 대사 반영.
- 보스 격파 후 감정 자체는 사라지지 않고 각자가 이겨내야 한다는 호반우 대사 반영.
- 챕터 2에서 과거 CH1 별을 표시하는 곳은 `시작의 별`, `적응의 별`로 갱신. CH2의 `시험의 별`, `팀플의 별`은 유지.
