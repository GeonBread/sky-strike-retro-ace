챕터 2·3 보스전 연출/화면 수정 V2

적용 대상: 디그리온 실제 보스전 통합 패치와 5개 전투 맵 패치를 적용한 프로젝트.
기존 프로젝트의 tools/chapter1_patch_runner/APPLY_PATCH.cmd 위에 이 ZIP을 그대로 드래그하세요.
압축을 풀거나 별도 설치 프로그램을 실행할 필요가 없습니다.

수정 내용
- 챕터 3 스토리 → 실제 보스전 진입을 18초 전용 시네마틱으로 교체했습니다.
  봉인 집결, 광문 개방, 디그리온 타이틀, 전투장 연결 순으로 진행합니다.
  그 뒤 원본 6.5초 보스 등장과 대사가 이어집니다.
- F6/SKIP으로 진입 연출을 넘겨도 실제 보스전으로 진입하며, 보스 클리어 전까지 스토리는 대기합니다.
- 등장/각성/클리어 장면과 일반 전투 모두 922×960 논리 화면과 균일 배율을 사용합니다.
  일반 전투의 캔버스 고유 너비가 화면 비율을 덮어쓰던 문제도 수정했습니다.
- 호반우 등장/각성/클리어 이미지는 전투와 같은 너비와 원본 2:3 비율로 표시합니다.
- 장면/패턴 테스트와 일시정지 버튼은 화면 오른쪽에 배치했습니다.
  F7 테스트 창의 연출 장면 선택 목록도 오른쪽에 고정했습니다.
- 1·2페이즈 각각의 테스트 목록을 일반 공격 / 특수 공격 / 보조 공격(해당되는 경우)으로 구분합니다.
  원래 전투 순번과 보조 공격 조합, 최초학습/숙련 설정을 유지합니다.
- 챕터 2·3 보스 맵은 챕터 1 보스의 기본 맵 속도와 동일하게 아래로 스크롤합니다.
  1페이즈 86px/s, 각성 112px/s, 2페이즈 122px/s, 처치 연출 94px/s입니다.
  페이즈 변경 시 위치가 튀지 않도록 누적 이동량을 사용하며 일시정지하면 배경도 멈춥니다.
- 진입 타이틀 전용 글꼴을 로컬에 포함했습니다. 인터넷 글꼴 로딩에 의존하지 않습니다.

검증: 타입 검사, 자동 테스트 212개, 프로덕션 빌드 통과.
글꼴: 제공된 디그리온 원본의 Black Han Sans를 타이틀용 문자만 추린 파생본입니다.
