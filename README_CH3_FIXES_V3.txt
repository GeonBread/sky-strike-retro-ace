챕터 3 보스·스토리 수정 V3 (2026-10-31)

적용 기준
- Game_Fixes_V2 적용본 (또는 Patch_Runner_Recovery의 Game_Fixes_V2 적용본).
- 이 ZIP은 기존 프로젝트 패치 프로그램이 읽는 프로젝트 상대경로 형식입니다.

적용
1. ZIP을 압축 해제하지 마세요.
2. 프로젝트의 tools/chapter1_patch_runner/APPLY_PATCH.cmd 위로 이 ZIP을 드래그하세요.
3. 이전에 배포한 잠금 파일 복구용 패치 프로그램을 그대로 사용하세요.

수정
- 지오메트리 비행 진입 시 약 0.65초 동안 균열과 입자로 디그리온이 사라집니다.
- 비행 중 디그리온 본체는 표시되지 않습니다.
- 마지막 비행 장애물이 해소된 뒤 약 0.7초 재등장 연출이 끝나야 다음 학습 단계/패턴으로 넘어갑니다.
- 일시정지하면 퇴장/재등장 연출도 함께 멈춥니다.
- 추방 공간의 사전 몬스터 배치, 부드러운 선회와 방향 사격은 유지합니다.
- 추방 몬스터 최대 수를 360 → 128마리로 줄이고 증원 간격을 완화했습니다.
- 화면 밖 몬스터 그리기를 생략하고, 발광 그림을 재사용하며, 탄환별 중복 표적 목록 생성과 정렬을 줄였습니다.
- 스토리 디그리온 첫 등장 중 이전 대사의 호반우 일러스트가 연출 위에 남거나 뒤늦게 다시 생기지 않게 수정했습니다.
- 다음 대사에서는 정상적으로 호반우 일러스트가 다시 표시됩니다.

검증
- 챕터 3 자동 테스트 230개 통과.
- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 브라우저에서 비행 퇴장/완전 숨김/재등장, 추방 공간 배치, 스토리 첫 등장과 후속 대사 복구 확인.
- 동일 헤드리스 브라우저의 최대 강화 과학 연사 조건에서, 2회 물리 갱신 + 1회 그리기 중앙값 약 29.4ms → 4.9ms.
  측정 환경에 따른 수치이며 사용자 PC의 FPS를 보장하는 값은 아닙니다.
