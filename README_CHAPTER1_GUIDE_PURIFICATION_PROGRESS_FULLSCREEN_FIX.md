# 챕터 1 전투 가이드·정화·진행률·전체화면 연출 수정

## 반영 내용

- 전투 배경과 호반우 스프라이트가 준비된 뒤 중앙 전투 가이드가 표시됩니다.
- 가이드 중 배경 렌더링은 계속되지만 웨이브 시뮬레이션과 조작은 정지합니다.
- 정화 이펙트는 호반우 중심에서 끝까지 재생한 뒤 호반우가 상승 이탈합니다.
- 상승 이탈 중 무적 깜빡임을 제거했습니다.
- 좌측 웨이브 번호를 제거하고 상단 중앙의 정화 에너지 진행률로 변경했습니다.
- 정화 후 학생증 대사를 끊어진 말투로 변경했습니다.
- 대화창이 숨겨진 배경 시네마틱에서는 Space 입력을 무시합니다.
- 학사 시스템 비상 통제와 보스 최초 등장 연출을 전체 뷰포트로 확대했습니다.
- 체력과 폭탄 HUD를 오른쪽 안전 여백 안쪽으로 이동했습니다.
