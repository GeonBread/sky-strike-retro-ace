호반우의 졸업 대작전 — 챕터 3 디그리온 실제 보스전 통합 V1

[적용 방법]
1. 이 ZIP을 압축 해제하지 말고 그대로 사용합니다.
2. 프로젝트 안의 기존 tools/chapter1_patch_runner/APPLY_PATCH.cmd 위에 드래그합니다.
3. 기존 패치 프로그램이 매니페스트의 파일을 읽어 적용하고 검사합니다.

별도 패치 실행기를 ZIP에 넣지 않았습니다.
기존 실행기의 백업·검증·자동 커밋·푸시 설정을 그대로 따릅니다.
기존 이미지와 음원은 그대로 사용하며 이 ZIP은 소스 변경만 적용합니다.

[실제 게임 연결]
장면 20 이후 기존 boss-battle-transition이 끝나는 시점에 실제 보스전이 시작됩니다.
스토리의 기존 항목 수와 대사 인덱스를 바꾸지 않았습니다.
첫 등장 → 도입 대사 → 1페이즈 → 가짜 클리어/도발 → 12초 각성 →
제4의 벽 대사 → 2페이즈 → 최후의 40초 → 마지막 사격 →
14초 최종 처치/정화 → 클리어 카드를 유지합니다.
클리어 카드의 '스토리 계속'을 누르면 장면 29 이후 기존 스토리로 이어집니다.
보스전 중 저장된 체크포인트는 보스전 처음부터 재개합니다.

[기본 조작과 테스트]
방향키/WASD: 이동 / SPACE: 사격 / X 또는 B: 폭탄
Enter 또는 SPACE: 보스 대사 완성·다음 문장
ESC: 일시정지 / R: 현재 도전 재시작
F7 또는 작은 TEST 버튼: 테스트 창 열기·닫기
F6: 다음 패턴으로 직접 이동 / F8: 현재 페이즈 클리어 연출

실제 플레이에는 시뮬레이터의 FPS, 로그, 속도 슬라이더, 임의 회전,
리소스 토글, 메인 메뉴 미리보기 등의 UI를 가져오지 않았습니다.
테스트 창에서 기본적인 패턴·연출·무적·탄 강화만 제공합니다.
테스트 창을 열면 전투와 연출 시간이 함께 멈춥니다.

테스트 창의 1페이즈 탭은 원본 편성 14개, 2페이즈 탭은 원본 편성 22개입니다.
같은 기본 패턴이 양쪽에 있으면 '공통 패턴', 아니면 해당 페이즈 전용으로 표시합니다.
각 항목은 그 페이즈에서 실제 사용되는 보조 공격 조합까지 함께 실행합니다.
동일 기본 패턴이라도 조합/편성 위치가 다르면 별도 항목으로 표시합니다.
'미편성 패턴'에는 전체 전투 편성에 들어가지 않은 원본 예비 패턴만 둡니다.
보조 공격은 실제 편성의 기본 공격과 조합해서 검증합니다.

개별 편성 테스트는 해당 항목을 반복하며 보스 HP로 페이즈가 끝나지 않습니다.
플레이어 피해는 기본적으로 적용되며 '테스트 무적'을 켤 수 있습니다.
최초 학습/숙련 선택은 개별 테스트에 적용됩니다.
전체 보스전은 자동 학습 정책을 사용합니다.

[최초 학습 / 숙련]
처음 만난 기본 패턴: 1 → 2 → 3 → 4단계
이미 만난 같은 기본 패턴: 3 → 4단계
한 편성의 공격 시간을 학습 단계 수로 나눠 진행하며,
이미 예고한 공격·레이저 꼬리·복귀 동작은 끝낸 후 다음 단계로 넘어갑니다.
추방처럼 포탈 복귀가 필요한 패턴은 실제 복귀가 단계 완료 조건입니다.
동일 패턴 기록은 1페이즈에서 2페이즈까지 유지됩니다.
전체 도전을 재시작하면 기록을 초기화합니다. 브라우저 영구 숙련 저장은 하지 않습니다.

[호반우 사격]
시뮬레이터의 고정 녹색 단발탄을 제거하고 프로젝트의 챕터 2 공용 함수를 연결했습니다.
발사 함수, 48px 논리 플레이어 크기, 전공별 탄 종류/개수/속도/대미지,
레벨 1~5, 이과 연사·휴식, 문과 연사, 예체능 유도·음악 빔,
기존 탄 이미지·잔상 렌더링을 공용으로 재사용합니다.
전공/기체 선택은 기존 앱 설정을 따릅니다.
메인 화면 변형·유체·화면 밖 추방에서는 해당 공간의 방향/좌표에 맞춰 변환합니다.
실제 프로젝트의 public/assets/common/player/bullets 이미지를 그대로 참조합니다.
그 이미지들은 원래 AI_CONTEXT에서 제외된 자산이므로 임의로 새로 만들지 않았습니다.

[보스 체력바와 수치]
기존 챕터의 짙은 내부·금색 프레임·보라색 게이지를 바탕으로
금속 이중 테두리, 여섯 별, 분할 게이지, 각성 색상과 정밀 퍼센트를 추가했습니다.
HP바 검술에도 같은 그림을 사용합니다. 외곽 566×38 크기와 검 충돌 범위는 유지했습니다.
공용 사격의 실제 화력에 맞춰 HP는 1페이즈 3200 / 2페이즈 5200으로 설정했습니다.
이는 초기 통합값이며 향후 플레이 밸런싱 대상입니다.
값은 src/game/chapter3/degreeon/encounter.ts의 PHASE_HP에 모아 두었습니다.
최후의 1% 생존전과 마지막 사격 조건은 원본 그대로입니다.

[검증]
npm run lint / npm run test:chapter3 / npm run build
자동 검증 202개 통과. 원본 패턴·예고·충돌·잔여 탄·각성·최후 생존 검증과
새로운 자동 학습, 페이즈별 테스트, 챕터 2 사격 동일성 검증을 포함합니다.
브라우저: 1440×900과 800×1100에서 UI와 주요 연출을 확인했습니다.
스토리 인덱스 212에서 실제 보스전 진입 후 클리어하여 214의 후속 대사로 복귀했습니다.
이 확인에서 JavaScript page error는 없었습니다.

첨부 AI_CONTEXT는 소스 전용이므로 챕터 1·2/기존 스토리의 전체 이미지·음원은 없습니다.
기존 자산을 가진 프로젝트에 적용하는 패치입니다. 완전한 단독 배포 ZIP은 아닙니다.
빌드의 기존 누락 자산 경로 경고와 번들 크기 경고는 실행을 막지 않으며,
이번 패치는 기존 자산을 삭제하거나 교체하지 않습니다.
이번 ZIP은 기존 패치 프로그램용 소스 묶음이며 미리보기 이미지는 포함하지 않습니다.
