# Chapter 2 Story / BGM / Boss UI Fix V1

기준: 2026-10-05 프로젝트 스냅샷 + 기존 Chapter 1 BGM V3 변경 보존.
이 패치는 Chapter 2 관련 파일 3개만 덮어씁니다.

## 반영 사항

1. 책임의 블랙홀 첫 입장 연출
   - 기존 보스 영역 도착 화면에 포탈 출구처럼 확장되는 보라색 aperture/공간 개방 연출을 추가했습니다.
   - 배경 카메라 이동 및 LOCATION 표시와 자연스럽게 연결됩니다.

2. 팀플 블랙홀 첫 등장 보스명 가독성 개선
   - 첫 등장 시 보스명 색을 순백색 계열로 올리고 외곽선/발광/그림자를 강화했습니다.
   - React 전체화면 등장 레이어에도 별도의 밝은 보스 타이틀을 추가했습니다.

3. 책임의 블랙홀 포탈 BGM 페이드
   - 실제 출발용 core-portal-open(index 239)에서 기존 일상 BGM을 복원한 뒤 약 3.6초에 걸쳐 페이드아웃합니다.
   - 도착(index 240) 이후 발표 장면 전까지는 프리보스 BGM 구간 상태를 유지합니다.

4. Word 저장 오류 / 오염 파편 연출
   - 첫 Word 오류 알림창이 나타나는 정확한 시점에 상황 BGM을 약 3초간 페이드아웃합니다.
   - effect-end 진행 이벤트가 페이드한 곡을 다시 켜지 않도록 index 111 처리를 분리했습니다.
   - 기존 '오염 반응 급상승' 연출은 스토리 흐름에서 제거했습니다(인덱스 보존용 짧은 비표시 wait만 유지).
   - 오염 파편 출현 화면은 3종 몬스터만 사용하고 각 3마리씩 총 9마리를 배치합니다.
   - 각 종류의 3마리는 삼각형 구성을 기본으로 하되 위치/크기/회전에 작은 랜덤 편차를 줍니다.
   - 몬스터는 9마리가 한 마리씩 순차 등장합니다.
   - 화면에 '오염 파편 출현' 제목 및 몬스터 이름 텍스트를 표시하지 않습니다.

5. 일반 몬스터 웨이브 전환 BGM 페이드
   - '일반 오염 전투' combat-transition(index 142) 시작 시 기존 오염 BGM을 복원한 뒤 약 2.8초간 페이드아웃합니다.

6. 예정된 중간 점검 BGM
   - 캘린더 time-card(index 164)에서 상황 BGM을 약 3.6초간 페이드아웃합니다.
   - 첫 대사(index 165)부터 Chapter 1 일상 BGM을 재생하고 책임의 블랙홀 출발 포탈 직전까지 유지합니다.
   - 중간 장면으로 직접 점프해도 해당 구간 BGM이 복원되도록 구간 상태로 처리합니다.

7. 팀플 블랙홀 전용 대사창
   - 기존 `boss` 화자가 등장할 때만 적용되는 전용 보스 대사창 스킨을 추가했습니다.
   - 챕터 3 디그리온 전용 대사창처럼 일반 대사창과 분리되며, 보라/금색 오염 보스 UI로 표시됩니다.
   - 현재 Chapter 2 스토리 데이터에는 `boss`의 직접 대사 문장이 없으므로 임의 대사는 추가하지 않았습니다. 이후 `speaker: "boss"` 대사가 사용되면 자동 적용됩니다.
