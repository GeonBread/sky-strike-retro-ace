# 챕터 1 몬스터 웨이브 통합 덮어쓰기 패치

이 ZIP은 기존 프로젝트 폴더 이름과 동일한 `sky-strike_-retro-ace` 구조로 제작되었습니다.

## 적용 방법

1. 기존 `sky-strike_-retro-ace` 프로젝트를 백업합니다.
2. 이 ZIP을 기존 프로젝트의 상위 폴더에서 압축 해제합니다.
3. 같은 이름의 폴더와 파일을 모두 덮어씁니다.
4. 프로젝트 루트에서 기존 방식대로 실행합니다.
   - 개발: `npm run dev`
   - 타입 검사: `npm run lint`
   - 빌드: `npm run build`

## 적용 범위

- 챕터 1 일반 전투를 새 몬스터 10종과 웨이브 30종으로 교체
- 기존 플레이어, 무기, 배경, 점수, 보스 시스템은 유지
- 마지막 30번째 웨이브가 끝나면 기존 보스 진입 흐름으로 연결
- 개발자 샌드박스의 단일 몬스터 목록과 웨이브 목록도 새 콘텐츠로 교체

## 새 몬스터

1. 출석체크 드론
2. 결석확인 드론
3. 공지사항 드론
4. 학번 발급 터미널
5. 통합정보 로그인 감시자
6. 수강편람 데이터 벌레
7. 시간표 충돌 블록
8. 잔여석 감지 드론
9. 장바구니 슬롯 박스
10. 강의실 좌표 왜곡기

## 이식된 특수 기능

- 공지 종탄 파괴 및 3초 주기 파동
- 시간표 블록 2초 경고, 낙하, 설치, 플레이어 탄 차단 및 파괴
- 장바구니 슬롯의 플레이어 탄 최대 8발 흡수 및 동일 수량 반사
- 좌표 화살표의 90도 방향 전환
- 로그인 잠금 카드 낙하 장벽
- 잔여석 드론 8방향 방사탄
- 웨이브 사이 남은 탄과 설치물 유지
- 마지막 웨이브 종료 시 적탄과 경고를 정리한 뒤 보스 진입

## 검증 내용

- 챕터 1 신규 모듈 strict TypeScript 검사 통과
- 웨이브 1부터 30까지 순차 실행 모의 테스트 통과
- 30번째 웨이브 종료 후 `clearingForBoss = true` 전환 확인
- 전체 수정 파일 TypeScript 구문 검사 통과

## 참고

현재 패치는 `stage === 1`의 일반 전투를 새 웨이브로 대체합니다. 기존 레거시 웨이브 코드는 이후 스테이지의 기존 흐름을 갑자기 중단시키지 않도록 내부에 남아 있지만, 챕터 1과 개발자 샌드박스에서는 사용되지 않습니다.

## 몬스터·탄 크기 및 원본 피격 효과 보강

- 일반 챕터 1 몬스터 표시 크기: 기존 통합본 대비 약 28% 확대
- 시간표 충돌 블록 몬스터: 과도한 화면 점유를 막기 위해 약 15% 확대
- 일반 전용 탄 표시 크기: 약 35% 확대
- 대형 로그인 잠금탄: 약 22% 확대
- 설치형 시간표 블록: 약 18% 확대
- 실제 충돌 판정은 시각 크기보다 적게 확대하여 회피 난이도 급증 방지
- 원본 웨이브 시뮬레이터의 충돌 지점 각진 스파크, 마름모 소멸선, 사방 방사선, 데이터 파편 효과 적용
- 몬스터 피격, 공지 종탄/시간표 블록 피격·파괴, 장바구니 흡수, 적탄의 플레이어·위성 충돌에 적용
- 시간표 블록 피격 시 원본의 흰색 점멸 및 약한 화면 흔들림 적용
