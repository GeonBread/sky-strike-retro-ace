챕터 3 디그리온 보스전 통합 V1 — 기존 ZIP 패치 프로그램용

[적용]
이 ZIP의 압축을 풀지 마세요.
프로젝트 안의 기존 tools/chapter1_patch_runner/APPLY_PATCH.cmd 위에
ZIP 파일을 그대로 드래그하여 놓으면 됩니다.

별도 설치 프로그램이나 새 패치 실행기를 추가하지 않았습니다.
ZIP 최상위에 src/, docs/, tests/, package.json, PATCH_MANIFEST.json이 있습니다.
기존 실행기는 PATCH_MANIFEST.json의 문자열 파일 목록으로 적용할 파일을 읽습니다.
기존 실행기의 백업·검증·자동 커밋·푸시 동작은 그대로 따릅니다.

[내용]
실제 스토리와 디그리온 보스전 연결, 각성/클리어 연출 유지,
챕터 2 공용 호반우 사격, 자동 최초 학습/숙련 전환,
페이즈별 편성 테스트, 최종보스 체력바가 포함되어 있습니다.
실제 전투에서 F7을 누르면 테스트 창을 열 수 있습니다.
1페이즈 14개 / 2페이즈 22개의 실제 보조 공격 조합을 구분합니다.

원래 프로젝트에 있는 보스/플레이어/탄 이미지를 그대로 사용합니다.
기존 이미지를 덮어쓰거나 삭제하지 않습니다.
원본 AI_CONTEXT는 바이너리 자산이 제외된 소스 스냅샷이므로,
원래 이미지와 음원을 가진 기존 프로젝트에 적용해 주세요.

[확인]
게임 소스는 앞서 검증한 통합본과 같습니다.
타입 검사·빌드 및 보스 자동 검증 202개를 통과했습니다.
브라우저에서 보스 진입·각성·클리어·후속 스토리 복귀를 확인했습니다.
이번 파일은 ZIP 내부 배치와 매니페스트를 기존 패치 프로그램 규격으로 바꾼 것입니다.

자세한 게임 조작과 변경 사항은 docs/chapter3-boss-integration.txt를 참고하세요.
