# MAIN_MENU_TIME_BACKGROUND_V10

V9.2 적용 상태 위에 적용하는 메인 화면 시간대 배경 패치입니다.

## 시간대
- 07:00 ~ 16:59: 아침/오후 - 기존 `main_menu_campus_bg.png`
- 17:00 ~ 19:59: 저녁 - `main_menu_campus_evening.png`
- 20:00 ~ 03:59: 밤 - 기존 챕터 3 `campus_night.png`
- 04:00 ~ 06:59: 새벽 - `main_menu_campus_dawn.png`

브라우저/PC의 로컬 시간을 사용하며 1분마다 자동 갱신합니다. 창을 다시 활성화할 때도 즉시 현재 시간대를 재확인합니다.
