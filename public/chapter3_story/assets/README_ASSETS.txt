assets 폴더 사용 규칙

1. 새 배경, 캐릭터, 초상화, 일러스트는 모두 이 폴더에 별도 파일로 넣습니다.
2. HTML이나 JavaScript에 base64/data URI로 직접 넣지 않습니다.
3. 파일명은 역할이 드러나도록 작성합니다.

권장 예시
- bg_chapter2_area01.png
- bg_chapter2_stairs.png
- hobanwoo_thinking.png
- hobanwoo_battle_ready.png
- monster_chapter2_guide.png
- portrait_chapter2_guide.png
- illustration_chapter2_core.png

현재 들어 있는 SVG 파일은 템플릿이 즉시 실행되도록 만든 자리표시자입니다.
실제 챕터 2 이미지로 교체해도 엔진 코드는 수정할 필요가 없습니다.
