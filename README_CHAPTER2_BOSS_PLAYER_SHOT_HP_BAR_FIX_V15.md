# Chapter 2 Boss Player Shot + HP Bar Fix V15

## 적용 기준
- `chapter2_boss_v68_story_integration_v14.zip`까지 적용된 프로젝트 위에 덮어쓰기.
- 프로젝트 상대 경로를 유지한 증분 패치.

## 1. 호반우 탄환 발사/표시 수정
기존 v14는 v68 보스 런타임의 `isPlayerAttackAllowed()`가 false인 동안
프로젝트의 플레이어 탄환 자체를 매 프레임 삭제하고 있었음.

특히 보스 등장 직후 첫 패턴인 201 `간단한 계산 문제`는 원본 v68에서도
정답 클릭으로 보스에 피해를 주는 특수 패턴이라 일반 사격 피해가 잠겨 있음.
그 때문에 실제 게임에서는 Space를 눌러도 호반우 탄환이 전혀 날아가지 않는 것처럼 보였음.

V15에서는 다음처럼 분리함.
- 호반우의 기존 Space 발사/탄환 생성/탄환 이동/탄환 렌더링은 유지.
- 201처럼 원본 보스에서 일반 사격 피해가 잠긴 패턴에서도 탄환은 정상적으로 화면 위로 날아감.
- 단, 그 패턴의 원래 룰을 깨지 않도록 해당 탄환은 보스 피해를 주지 않음.
- 보스 등장, 페이즈 전환, 최종 사망/CLEAR 같은 전체 화면 시네마틱에서만 남은 플레이어 탄환을 정리함.
- 일반 패턴에서는 기존 호반우 탄환이 보스 및 파괴 가능 오브젝트에 정상 피해를 줌.

추가로 스토리 iframe에서 보스전으로 넘어온 직후 키보드 포커스가 iframe에 남아
Space 입력이 부모 게임 캔버스로 전달되지 않을 가능성을 제거함.
- 전투 캔버스를 `tabIndex=0`으로 설정.
- 스토리 전투 캔버스가 활성화되면 자동으로 포커스함.

## 2. v68 보스 체력바 디자인 복원
v14에서는 보스 랩의 HUD 전체를 꺼 두면서 v68 원본 보스 체력바까지 함께 비활성화되어 있었음.
V15에서는 플레이어 LIFE HUD는 계속 사용하지 않고, **보스 체력바만 원본 v68 디자인 그대로 복원**함.

복원되는 요소:
- `시험·팀플 블랙홀 무임승차자` 보스명 패널
- 1페이즈 / 2페이즈 배지
- 원본 크림색 외곽 프레임과 양쪽 캡
- Phase 1 청록 계열 / Phase 2 적색 계열 HP 그라디언트
- 우측 HP 퍼센트 표시
- 보스 최초 등장 시 0% -> 100% 충전 연출
- 1페이즈 사망 시 HP 감소 연출
- 2페이즈 각성 시 0% -> 100% 재충전 연출

원본 v68 `cinematicHpRatio()` 및 `drawSharedBossHealthBar()`를 그대로 사용하므로
등장/전환 연출의 체력바 타이밍 역시 원본과 동일함.

## 3. 중복 보스 체력바 제거
기존 프로젝트에 임시로 표시되던 React 기본 보스 HP 바는 Chapter 2 Boss 전투에서 숨김.
따라서 보스전에서는 v68 원본 체력바 한 개만 표시됨.

플레이어 HP 3칸, 폭탄 3개, 호반우 캐릭터, 기존 게임 HUD는 그대로 유지함.
