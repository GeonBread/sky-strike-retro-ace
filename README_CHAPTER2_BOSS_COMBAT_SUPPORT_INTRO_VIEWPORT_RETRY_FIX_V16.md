## 1. 보스 타격 판정
- Chapter 1 보스의 플레이어 탄 판정 방식과 동일하게 플레이어 탄 중심을 보스 타격 타원에 직접 대입하여 판정함.
- 일반 플레이어 탄은 타격 즉시 소멸하고 `core.applyDamage(bullet.damage)`를 직접 호출함.
- 예체능 `musicBeam`은 Chapter 1과 동일하게 0.12초 간격 연속 타격으로 처리함.
- 보스 본체를 빗나간 탄만 v68 패턴 오브젝트 판정으로 전달함.
- 수학/계산 패턴에서도 실제 전투 중에는 보스 타격이 가능하도록 수정함. 컷신/클리어/패턴 종료 정리 중에만 타격 잠금.
- 공유 문서함 드론이 살아 있는 동안의 v68 보스 보호막 규칙은 패턴 고유 규칙이므로 유지함.

## 2. Chapter 2 보스 지원 일반몹
- Chapter 2 웨이브의 페이지/보고서 드론 외형을 사용함.
- 한 번에 정확히 2마리만 등장함.
- 기존 드론의 복잡한 부메랑 공격은 사용하지 않고 플레이어 방향 단발 탄환만 발사함.
- 현재 2마리가 살아 있는 동안 추가 소환하지 않음.
- 둘이 제거된 뒤 일정 시간이 지나면 다음 2마리가 다시 등장함.
- 플레이어 탄 충돌, 적 사망, 폭발, 아이템 드롭은 Chapter 1 보스 지원몹과 동일하게 공통 Enemy/Collision 시스템을 사용함.
- 페이즈 전환/등장 컷신/사망 컷신/클리어에서는 지원몹과 지원몹 탄환을 정리함.

## 3. Chapter 2 보스전 시작 연출
- 단순 `보스전 시작` 표시 대신 브라우저 전체 화면 보스 진입 연출을 추가함.
- 붉은 셔터, 대각선 슬래시, 경고 링, WARNING 라인, `BOSS APPROACH`, 보스명 표시 후 실제 전투로 연결함.
- 테스트로 특정 보스 패턴에 직접 점프하는 경우에는 해당 전체 인트로를 생략함.
- F6으로 인트로 즉시 스킵 가능.

## 4. 사망 후 재도전 알림창
- Chapter 1 / Chapter 2 전투 사망 후 재도전 확인 UI를 ESC 일시정지/메인화면 확인창과 같은 `chapterGamePauseDialog` 디자인으로 통일함.
- Chapter 2 웨이브 재도전은 현재 웨이브 처음부터, 보스 재도전은 1페이즈부터 시작함.

## 5. Chapter 2 보스 화면 크기
- Chapter 1 스토리 전투와 동일한 922 x 960 논리 화면을 사용함.
- v68의 800 x 960 화면을 가로로 강제 확대하지 않음.
- 보스 이미지, 탄환, 글자, 버튼, 드론 등 개별 요소는 1:1 픽셀 크기/종횡비를 유지함.
- Kakao / Zoom / PPT / Word처럼 화면 자체를 차지해야 하는 패턴은 외부 패널/배경 폭과 배치 간격만 922 폭에 맞춰 확장함.
- 내부 아이콘/말풍선/타일/폰트/버튼 자체는 비균일 스케일하지 않음.
- 원래 800폭 기준 좌우에 놓이던 일부 패턴 오브젝트는 `W` 기준으로 재배치하여 922 폭을 자연스럽게 사용함.

## 검사
- 수정 TS/TSX 10개 파일 `TypeScript.transpileModule` 문법 검사 통과.
- 프로젝트 전체 `tsc --noEmit`은 경량 통합 소스에 `node_modules`가 없어 React/Vite 등 외부 모듈 타입을 찾지 못하는 의존성 오류만 발생함. 이번 변경 파일 자체의 추가 TS 구문 오류는 transpile 검사에서 발견되지 않음.
- Chapter 2 보스 내부 해상도 922 x 960 / projection 922 x 960 정적 확인.
- 지원몹 동시 생성 수 2 / 추가 생성 전 liveCount 0 조건 정적 확인.
