챕터 3 웨이브 로딩 / 보스 패턴 및 배경 가시성 수정 V2

직전 Map_Layers_Update.zip 적용본용입니다.
압축을 풀지 말고 프로젝트의 tools/chapter1_patch_runner/APPLY_PATCH.cmd로 드래그하세요.

1. 배경 가시성
- 보스 2 구름을 더 진하게 표시합니다(레이어 불투명도 68~82%).
- 챕터 1·2 정화 파편은 추가 투명도 없이 원본 PNG 알파로 표시합니다.
- 챕터 2의 맵 어둡게 처리도 정화 파편 위에 덮이지 않도록 순서를 수정했습니다.

2. 챕터 3 웨이브 로딩
- 외부 부가 배경 스크립트 요청 실패로 웨이브 초기화가 중단되는 경로를 없앴습니다.
- 독립 HTML 안에 배경 런타임을 포함합니다. 배경 모듈이 없어도 본 전투 초기화를 막지 않습니다.
- 준비 신호 재확인 및 실제 HUD 수신 확인을 추가했습니다.
- 초기화 오류 또는 응답 지연 시 계속 로딩하지 않고 다시 불러오기 버튼을 제공합니다.

3. 스토리 전환
- 스토리 → 웨이브: 4.2초 화면 전체 시각 연출 후 실제 전투로 바로 연결합니다.
- 스토리 → 보스: 18초 순수 시각 연출로 바꿨습니다. 문구, 이름 타이틀, 디그리온 외형을 모두 제거했습니다.
- 본 보스전 안의 등장·각성·처치 연출과 스토리 연결은 유지합니다.

4. 화면 밖 추방
- 추방 직후부터 바깥 맵 전체에 몬스터를 배치합니다. 착지 지점과 복귀 포탈 주변에는 안전 공간을 둡니다.
- 화면 바깥에서 추가 몬스터가 유입되어 탐색 중 밀도를 유지합니다.
- 방향키 조향 시 현재 방향에서 부드럽게 선회하며 이동 방향을 바꿉니다.
- 기존 챕터 2 탄 로직을 유지하면서 발사 위치·속도·탄 모양이 현재 선회 방향을 따릅니다.

5. 지오메트리 비행
- 가로 전장을 브라우저의 전체 가로 길이까지 확장하며 창 크기를 바꿔도 맞춥니다.
- 중력이 향하는 아래쪽을 가리키는 화살표를 추가했습니다.
- 스페이스바는 상승 조작 전용으로 사용하고 탄환은 발사하지 않습니다.
- 넓어진 전장에서 장애물이 플레이어에게 도달할 수 있도록 생존 시간을 조정했습니다.

6. 호반우 부유
- 보스 첫 등장과 대사·각성·클리어 중에도 일반 전투와 같은 부유·미세 회전을 적용합니다.
- 일시정지하면 부유도 멈춥니다.

검증
- 타입 검사, 자동 테스트 225개, 프로덕션 빌드 통과.
- 실제 프로덕션 빌드에서 준비 신호 유실, 초기화 오류→재시도 복구, 스토리→웨이브/보스 연결을 확인했습니다.
- 추방 후 몬스터 배치, 등장 중 부유, 1440px/800px 가로 비행 화면 및 스페이스바 발사 금지를 브라우저에서 확인했습니다.
