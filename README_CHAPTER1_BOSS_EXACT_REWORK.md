# 챕터 1 보스 원본 코드 재이식본

이 패치는 이전 유사 재구현 보스 코드를 폐기하고, 원본 `챕터1_보스_인증번호패드_반응형수정.html`의 전투 코드를 직접 감싼 런타임으로 교체합니다.

## 원본 그대로 유지한 범위

- PATTERNS 배열과 패턴 지속시간
- 1페이즈 패턴 6종 및 2페이즈 패턴 10종
- 보스 이동 함수와 패턴별 이동 궤도
- 탄 생성 수치, 발사 간격, 속도, 분열·정지·역행·도탄 상태
- 레이저 추적·고정·발사 시간표
- 서비스 접속 대기열
- 수강신청 클릭탄
- 출석 쟁탈전 3라운드
- 4자리 인증코드와 숫자 패드
- 공지 전광판, 강의실 좌표, 안내 방송, NFC, 읽지 않은 알림, 강제 동기화
- 특수 패턴별 종료 조건
- 패턴 전환 시 잔존 투사체 규칙
- 1페이즈 파괴, 각성, 2페이즈 HP 충전, 최종 파괴 시네마틱
- 원본 보스·탄·특수 패턴 렌더 함수

## 현재 프로젝트와 연결한 부분

- 현재 호반우 플레이어 좌표와 원본 보스 판정 좌표 동기화
- 현재 플레이어 피격·부활 시스템 호출
- 현재 플레이어 탄으로 원본 타원형 보스 피격 영역 공격
- 스마트 폭탄 1회 데미지 연결
- 키보드 숫자, 마우스 및 모바일 숫자 패드 입력 연결
- 웨이브 30 종료 후 보스 시작, 보스 종료 후 스테이지 클리어 연결

## 함께 포함된 일반 웨이브 수정

- 일반 몬스터와 탄 추가 확대
- 일반 몬스터 HP 1.3배
- 시간표 충돌 블록 착지 시 화면 진동, 충격파, 바닥 스트릭, 파편 효과
