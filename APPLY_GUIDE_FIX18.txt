   - 배경 확대 + 중앙 광원 확산 + 주변 비네트 터널 연출로 변경

   - isDead 상태는 유지해 이동/사격/추가 피격 차단

3. 예체능 탄 유도 복원
   - 팔레트/장구/스포츠볼/호루라기 전부 유도탄으로 복원
   - 음악 레이저의 기존 타깃 추적 방식 유지
4. 스토리 대사창 세로 중앙 정렬 보정
   - 다이아몬드와 텍스트 블록을 대사창 실제 세로 중앙에 배치
   - 위/아래 패딩 균등화

적용 방법
1. 현재 프로젝트를 백업하거나 git status로 작업 상태를 확인합니다.
2. ZIP을 압축 해제합니다.
3. 압축 안의 sky-strike_-retro-ace 폴더 내용을 기존 프로젝트에 그대로 덮어씁니다.
4. Windows PowerShell에서 프로젝트 폴더로 이동합니다.
5. npm.cmd run dev 로 동작을 확인합니다.
6. 가능하면 npm.cmd run build 또는 npx.cmd tsc --noEmit 으로 추가 확인합니다.
